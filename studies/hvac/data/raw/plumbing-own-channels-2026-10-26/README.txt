Plumbing own-channel title-format study, pulled 2026-10-26 (UTC). Helper scratch folder; not a repository.
tab_<ch>.json      YouTube channel Videos tab (Latest/Popular/Oldest sorts), yt_allsorts.py, logged-out
exact_<ch>.jsonl   exact views + upload date per long-form video, vid_next_batch.py (innertube /next)
videos_<ch>.csv    one row per long-form video: id,title,date,views,multiple,F_main,F_mod,... sorted by multiple
format_scoreboard.csv  per-format counts/medians across all 4 channels, 4 windows
Normal = median views of long-form uploads aged 14-90 days on 2026-10-26 (uploaded 2026-07-28..2026-10-12).
Long-form = Videos-tab duration >= 3:00. Vintage Pipefitter: pre-2026-03 uploads (2009-2019 gaming/clips, aged channel) excluded.
F tags = rule-based reading (scripts/tag.py) with manual overrides; F_main + one modifier. Tags are a reading, not measured.
